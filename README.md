# PlatinumTrade.App

Official release repository for the **Platinum Trade** desktop application.

## Download

Download the latest stable or beta release from the **[Releases](https://github.com/vntradesoft/PlatinumTrade.App/releases)** page.

| File | Description |
|---|---|
| `PlatinumTrade-*-win-x64.zip` | Portable - extract and run directly |
| `PlatinumTrade-*-Setup.exe` | Installer - recommended for most users |
